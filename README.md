# applied-computational-intelligence

Homework 1 de Inteligência Computacional Aplicada (ICA) - análise exploratória do dataset de risco de diabetes.

## Como rodar

O código está todo em `homework1.ipynb`. Precisa de Python 3 com pandas, matplotlib e numpy:

```
pip install pandas matplotlib numpy
```

Depois é só abrir o notebook (Jupyter ou Colab) e rodar as células em ordem. O dataset usado já está em `dataset/diabetes_risk_prediction_dataset.csv`.
